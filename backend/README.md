# Backend

This folder will contain the FastAPI service and its tests. It will validate data, enforce eligibility rules, obtain route information through a provider-neutral interface, calculate coverage, run the OR-Tools placement model, and evaluate rendezvous candidates.

Core modules planned: `main.py`, `models.py`, `config.py`, `routing.py`, `coverage.py`, `deployment_optimizer.py`, `rendezvous.py`, and `simulation.py`.
