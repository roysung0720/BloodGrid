# Project Context

BloodGrid is a two-person HackGT project for rural EMS prehospital-blood logistics. The team is using coding agents extensively and has limited traditional programming experience.

## Working principles

- Favor the simplest architecture that demonstrates the real product idea.
- Make the map and calculated recommendations easy to explain in a live demo.
- Protect the MVP before adding polish or stretch features.
- Prefer free, local, and open-source tools.
- Use real public geography where practical; use realistic synthetic operational data where real data are unavailable.
- Clearly document what is synthetic and why.
- Keep rules deterministic and inspectable rather than delegating core decisions to an LLM.

## Intended users

BloodGrid is for EMS operations leadership, dispatch personnel, and regional EMS planners. It complements existing CAD, EMS, and blood-management systems; it does not replace them.
